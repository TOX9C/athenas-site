What’s new.

Release notes from the repo. New builds appear here as they ship.

v0.3.0

Beta, with agent activity detection

August 2026

Athena’s Core now sees which AI agents are running inside each pane. A gold dot marks an agent at work, a pulsing dot means thinking, amber means finished or waiting on you. Finished, errored, or questioning agents ping you with a macOS notification and a dock badge, so nothing waits unseen.

Also in this build:

  • Multi-pane terminal: several shell sessions side by side
  • Workspace-aware AI chat: talk to Claude or other LLMs inline
  • Swarm orchestration: launch multiple agents on a shared goal
  • Kanban tasks, a plugin system, an in-app browser, and 16 themes
